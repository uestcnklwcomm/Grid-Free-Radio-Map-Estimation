This repo contains the source code and dataset of paper 'Grid-Free Radio Map Estimation via Unsupervised Implicit Continuous Representation', publihsed in IEEE Signal Processing Letters.

Script Grid_Free_RME_FSD implement the approach on a simulated dataset, established by following the criteria in:

** S. Shrestha, X. Fu, and M. Hong, “Deep spectrum cartography: Completing radio map tensors using learned neural models,” IEEE Trans.
Signal Process., vol. 70, pp. 1170–1184, Jan. 2022. ** with a higher resolution.
