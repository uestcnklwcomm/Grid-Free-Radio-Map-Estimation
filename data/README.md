FSD_R8.mat and FSD_R10.mat include the fully synthetic data of radio maps, with the number of emitters being 10 and 8 respectively.
Radiomapseer_R2_IRT4.mat includes the radio map seer data under model intelligent ray-tracing 4, with two emitters.
Radiomapseer_R8_IRT2.mat includes the radio map seer data under model intelligent ray-traicing 2, with 8 emitters.
Radiomapseer_R10_DPM.mat includes the radio map seer data under dominant path model, with 10 emitters.
building_location_index includes the indices of building locations in a radio map seer data matrix.
